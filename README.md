# Khadizhat Khizrieva — Portfolio

Personal portfolio of a software developer in Montréal, built with hand-written HTML, CSS and JavaScript.

**Live site:** https://kkportfolio-lac.vercel.app

## Features
- Five pages: Home, Projects, Skills, Experience, Contact
- Bilingual English / French switch
- Light and dark matcha themes
- Project filter built with pure CSS (`:has()` selector, no JavaScript)
- Animated topographic map drawn on a canvas
- Click-to-enlarge screenshot viewer
- Scroll animations with IntersectionObserver
- Responsive layout for desktop, tablet and phone

## Built with
HTML5 · CSS3 (Grid, Flexbox, custom properties, color-mix) · JavaScript · Inline SVG · Canvas

## Hosting
Deployed on Vercel.
